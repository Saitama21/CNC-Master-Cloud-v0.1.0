# CNC Master Cloud Engineering Client v2.1.2

Веб-клиент открывается по адресу:

```text
https://ВАШ-ДОМЕН-API.up.railway.app/client
```

## Что реализовано

- загрузка PDF и отрисовка выбранной страницы;
- полуавтоматический поиск линии контура на скане;
- ручная калибровка масштаба по известному размеру;
- установка X0/Z0 и ручное редактирование токарного контура;
- наложение фактической заготовки на целевой контур;
- несколько операций и отдельный инструмент для каждой операции;
- выбор инструмента из каталога;
- построение траекторий и итогового профиля;
- карта параметров ShopTurn Stock Removal;
- пошаговая инструкция по каждому инструменту;
- проектный G-код и экспорт `.mpf`;
- сохранение инженерных проектов в PostgreSQL;
- лимиты админ-панели: `engineering_client`, `pdf_scan`, `gcode_generate`.

## Важное ограничение

Автоматическое распознавание произвольного скана не является измерительной системой. Клиент показывает кандидат контура, после чего оператор обязан задать масштаб и проверить/исправить точки вручную. Сгенерированный G-код является проектным: обязательны симуляция стойки, проверка коррекций, нулей, зажимов и сухой прогон.

## Новые зависимости

- `python-multipart`
- `PyMuPDF`
- `numpy`
- `opencv-python-headless`

Railway пересоберёт сервис `api` после обновления `requirements.txt`.
