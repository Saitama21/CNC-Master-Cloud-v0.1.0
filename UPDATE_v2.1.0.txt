Обновление поверх рабочего Telegram-бота.

Добавлено:
- цифровой паспорт станка в /client;
- загрузка профиля станка из API по Telegram ID и ID станка;
- Tengyue CK52PT-Y / SINUMERIK 828D как рабочая конфигурация;
- оси X/Z/Y/C, патрон, Renishaw и приводной инструмент;
- редактор револьвера T1-T15;
- сохранение конфигурации револьвера локально и внутри проекта;
- вкладка Станок / револьвер;
- расширенный payload генератора и проектов.

Railway:
1. Заменить файлы репозитория содержимым архива.
2. Не удалять переменные BOT_TOKEN, DATABASE_URL, API_BASE_URL, PUBLIC_BASE_URL, ADMIN_KEY.
3. Дождаться ACTIVE у API и Bot.
4. В Telegram открыть Мой станок -> CNC-клиент.
