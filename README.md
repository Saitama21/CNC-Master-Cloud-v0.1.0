# ⚙️ CNC Master Cloud FULL PRO v1.0.0

Telegram-платформа для операторов, наладчиков и технологов ЧПУ.

**Создатель:** Єрошов Іван

## Что входит в FULL PRO

### 🔩 Инструмент

- подбор по операции, материалу ISO P/M/K/N/S/H и реальным размерам;
- готовый каталог из **1067 стандартных позиций и комбинаций**;
- токарные державки, расточные державки, сменные пластины;
- канавочные и отрезные системы;
- наружный и внутренний резьбовой инструмент;
- HSS, HSS-Co, твердосплавные и корпусные сверла;
- концевые, сферические, фасочные, корпусные, торцевые и резьбовые фрезы;
- цанговые, гидравлические, термоусадочные и сверлильные патроны;
- сохранение выбранных позиций отдельно для каждого станка;
- добавление собственных позиций через веб-админку.

Каталог построен по распространённым ISO/DIN-семействам. Это не копия всех SKU всех брендов: точную марку сплава, стружколом, покрытие, винт, подкладку и совместимость необходимо сверять с каталогом выбранного производителя.

### 🧩 Несколько операций

Пользователь отмечает сразу несколько операций, выбирает материал, вводит параметры каждой операции и получает единый комплект:

- черновое и чистовое точение;
- торцевание;
- расточка;
- канавки и отрезка;
- наружная и внутренняя резьба;
- сверление;
- фрезерование приводным инструментом.

Комплект сохраняется в PostgreSQL как техпроцесс выбранного станка.

### 🧮 Калькуляторы

- обороты по Vc и диаметру;
- Vc по оборотам и диаметру;
- подача мм/мин и мм/об;
- подача фрезы по `n × z × fz`;
- время точения, сверления и фрезерования;
- конусность и угол;
- подача при нарезании резьбы;
- съём металла при точении;
- теоретическая Ra;
- координаты отверстий по делительной окружности.

### ⏱ Админ-панель лимитов

В `/admin` можно для каждой функции задать:

- включена она или выключена;
- число использований **на одного пользователя в час**;
- часы доступности, например `08:00–20:00`;
- временную зону, по умолчанию `Europe/Kyiv`;
- персональное правило для конкретного Telegram ID;
- безлимитный доступ отдельному пользователю.

Функции с отдельными лимитами:

- подбор инструмента;
- каталог;
- несколько операций;
- калькуляторы;
- проверка G-кода;
- ошибки стойки;
- техпроцесс;
- G/M-коды.

## Railway

Для этой версии нужно обновить **оба сервиса**: `api` и `bot`.

Команды запуска:

```text
api: uvicorn app.api_main:app --host 0.0.0.0 --port 8000
bot: python -m app.bot_main
```

Новые таблицы создаются API автоматически при запуске. Существующие данные станков и пользователей сохраняются.

Переменные:

```env
BOT_TOKEN=...
ADMIN_KEY=длинный_секрет
ADMIN_TELEGRAM_IDS=123456789,987654321
DATABASE_URL=postgresql+asyncpg://cnc:cnc@db:5432/cnc_master
REDIS_URL=redis://redis:6379/0
API_BASE_URL=http://api:8000
DEFAULT_TIMEZONE=Europe/Kyiv
```

`ADMIN_TELEGRAM_IDS` — необязательный список Telegram ID администраторов. Эти пользователи обходят часовые лимиты.

## Установка обновления

1. Загрузить содержимое архива в корень GitHub-репозитория с заменой файлов.
2. Убедиться, что пути выглядят как `app/bot_main.py`, а не `app/app/bot_main.py`.
3. Добавить в Railway переменную `ADMIN_TELEGRAM_IDS`, если нужен безлимит администратора.
4. Дождаться нового `ACTIVE` сначала у `api`, затем у `bot`.
5. Отправить боту `/start`.
6. Открыть админку по адресу домена API + `/admin`.

## Безопасность

Расчёты и подбор являются стартовыми рекомендациями. Перед обработкой обязательны проверка паспорта станка, фактической комплектации, каталога производителя инструмента, симуляция, Single Block, Dry Run и безопасный Override.
