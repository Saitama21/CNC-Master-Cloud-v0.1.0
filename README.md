# CNC Master Cloud v2.9.0

Инженерный веб-клиент и Telegram-платформа для операторов, наладчиков и технологов ЧПУ.

**Создатель:** Єрошов Іван  
**Основной модуль версии:** Manual Contour Stock Removal

## Что изменилось в v2.9.0

Основной способ построения токарного контура теперь не зависит от OpenAI:

1. загрузить PDF или фотографию чертежа;
2. нажать **«Ставить маркеры»**;
3. щёлкнуть по точкам профиля от торца `Z0` вглубь детали;
4. вписать точные значения `X/Z` в таблице;
5. нажать **«Рассчитать Stock Removal»**.

Клиент автоматически формирует:

- подтверждённый контур X/Z;
- черновые проходы по фактической заготовке;
- количество проходов по заданной глубине резания;
- оценку максимального радиального съёма;
- расчётный объём снимаемого материала;
- графическую проверку профиля и траекторий;
- карту Stock Removal для SINUMERIK 828D;
- пошаговую инструкцию по инструментам;
- проектный MPF/G-код.

AI-контур и AutoContour сохранены как дополнительные режимы. Для ручного маркера `OPENAI_API_KEY` не требуется.

## Запуск в Railway

Обновить содержимое репозитория файлами из архива. Структура должна начинаться сразу с:

```text
app/
Dockerfile
requirements.txt
README.md
```

Команды сервисов:

```text
api: uvicorn app.api_main:app --host 0.0.0.0 --port 8000
bot: python -m app.bot_main
```

Основные переменные Railway:

```env
BOT_TOKEN=...
ADMIN_KEY=длинный_секрет
ADMIN_TELEGRAM_IDS=123456789
DATABASE_URL=postgresql+asyncpg://cnc:cnc@db:5432/cnc_master
REDIS_URL=redis://redis:6379/0
API_BASE_URL=http://api:8000
PUBLIC_BASE_URL=https://ваш-api-домен.up.railway.app
```

Необязательные переменные AI:

```env
OPENAI_API_KEY=sk-...
OPENAI_DRAWING_MODEL=gpt-5-mini
```

Веб-клиент открывается по адресу:

```text
https://ваш-api-домен.up.railway.app/client
```

## Безопасность

Результат является инженерной заготовкой, а не разрешением на запуск станка. Перед обработкой обязательны проверка X/Z, режима диаметр/радиус, G54, коррекций инструмента, зажимов, графическая симуляция, Single Block, Dry Run и уменьшенный Rapid Override.
