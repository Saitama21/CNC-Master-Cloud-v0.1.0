# ⚙️ CNC Master Cloud v0.2.1

Telegram-платформа для операторов, наладчиков и технологов ЧПУ.

**Создатель:** Єрошов Іван


## Изменение в v0.2.1 — обязательный выбор станка

- Раздел «🔧 Мой станок» всегда показывает список профилей, даже если сохранён только один станок.
- В кнопке выбора отображаются название станка и модель стойки.
- В список добавлена кнопка «➕ Добавить ещё станок».
- После выбора открывается рабочая панель конкретного станка.

## Новое в v0.2.0 — модуль «🔧 Мой станок»

- характеристики выбранного станка;
- расшифровка возможностей осей X/Y/Z/C/A/B;
- подбор семейства инструмента и пластин по операции и ISO-группе материала;
- расчёт оборотов и минутной подачи для точения и фрезерования;
- создание и сохранение операций в PostgreSQL;
- формирование простого техпроцесса;
- статическая проверка типовых рисков G-кода;
- первичная диагностика ошибок стойки;
- карточка Tengyue CK52PT-Y по данным шильдика владельца.

## Обновление существующего Railway-развёртывания

1. Замените файлы репозитория файлами из этого архива.
2. Сделайте commit в ветку `main`.
3. Railway автоматически пересоберёт `api` и `bot`.
4. API при запуске создаст новую таблицу `machining_operations` автоматически.
5. Переменные Railway менять не нужно.

Команды запуска остаются:

- API: `uvicorn app.api_main:app --host 0.0.0.0 --port 8000`
- bot: `python -m app.bot_main`

## Безопасность

Проверка G-кода статическая и не заменяет симуляцию, Single Block, Dry Run, снижение Rapid Override и проверку корректоров. Рекомендации по инструменту и режимам являются стартовыми и должны сверяться с каталогом конкретного производителя.
