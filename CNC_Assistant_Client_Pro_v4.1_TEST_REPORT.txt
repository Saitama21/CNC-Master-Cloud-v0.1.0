CNC Assistant Client Pro v4.1 — UNIVERSAL DRAWING IMPORT
Дата: 2026-07-30

РЕАЛИЗОВАНО
1. Единый определитель форматов: PDF, PNG/JPG/WEBP, DXF, STEP/STP, IGES/IGS, SVG, STL, SLDPRT/SLDASM/SLDDRW.
2. Автоматический выбор маршрута обработки:
   - STEP -> CAD/B-Rep worker;
   - DXF -> точный 2D векторный контур;
   - PDF -> векторный разбор или OpenCV/AI;
   - фото -> OpenCV/AI с калибровкой;
   - SolidWorks native -> обязательный экспорт в STEP/DXF, без ложного «распознавания» бинарного файла.
3. Новый API: POST /api/v1/client/drawing/import.
4. Интерфейс принимает CAD-форматы и показывает формат, маршрут и ожидаемую точность.
5. Добавлен минимальный ASCII DXF parser для LINE/LWPOLYLINE, сохраняющий ступени с одинаковым Z.
6. Ограничение файла 50 МБ и понятные сообщения об ошибках.

ВЫВОД
Импорт и маршрутизация работают. Для данных PDF автоматический профиль нельзя безопасно применять без подтверждения: чертежи содержат сложные виды/размерные линии. Правильный рабочий маршрут: выделить продольный или осевой вид -> OpenCV -> AI-контур -> подтвердить ключевые размеры -> геометрическая проверка -> Stock Removal -> симуляция SINUMERIK.

PRODUCTION NEXT
Для реального извлечения B-Rep из STEP/IGES нужен отдельный worker на OpenCascade/FreeCAD. Текущая версия принимает и валидирует CAD-файл, но не притворяется, что извлекла точную 3D-геометрию без CAD-ядра.
